Simulated lifecycle

Simulation in a temporary MLflow registry on the real train/test splits; the served model is not touched.

  1. promotev1 baseline (v1)

    PR-AUC 0.5269 · Brier 0.1377 · ECE 0.0140 · cost 0.5858 · production none → v1

    First model: default hyper-parameters, 50% of the training rows.

  2. promotev2 retrained (v2)

    PR-AUC 0.5599 · Brier 0.1346 · ECE 0.0142 · cost 0.5562 · production v1 → v2

    Tuned hyper-parameters, all training rows (new labelled outcomes).

  3. rejectv3 noisy labels (v3)

    PR-AUC 0.5417 · Brier 0.1366 · ECE 0.0232 · cost 0.5638 · production v2 → v2

    Same recipe, but the outcome feed recorded 40% of defaults as repaid.

  4. rejectv4 uncalibrated (v4)

    PR-AUC 0.5599 · Brier 0.1764 · ECE 0.1903 · cost 0.5553 · production v2 → v2

    Same base model as v2 served without calibration (scores inflated by class weights).

  5. rollback@production v2 → v1

    simulated incident: a downstream system reports an unexpected decline-rate jump after the latest promotion; roll back while it is investigated
