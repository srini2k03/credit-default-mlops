The form posts to /explain on the live FastAPI service with the cutoff as ?threshold=. The API validates every field (out-of-domain values return 422), so the page never guesses. SEX, MARRIAGE and AGE are accepted but not used by the model; they only feed the fairness reports.

Examples load real test-split applicants (public UCI data) and the Swagger examples. Their precomputed results were produced at build time by the committed bundle that the API serves, and are labelled as such.
