01Drift scenarios

Drift is not one thing.

Covariate shift, a broken feed, new category codes, a riskier applicant mix, prior shift and concept drift each need a different response. The UCI table has no timestamps, so the batches are simulated and documented in credit_default.monitor.scenarios.

Block when any input misses more than 2% or unseen codes appear. Retrain (a gated challenger) when more than 30% of features drift or prediction PSI ≥ 0.2 while no labels exist yet, or once ≥ 1,000 labels arrive, when ROC-AUC drops by more than 0.03, the calibration gap exceeds ±0.05, or the deployed cutoff costs more than 5% above the batch optimum. With labels, drift that the model demonstrably handles is only monitored. Significance alone never triggers an action: with thousands of rows, KS flags shifts too small to matter.

02Data quality

Validated before it is trusted.

The Pandera contract stops the pipeline on a violation; this report describes what passed.

Rows

Contract
PASS (Pandera: types, domains, ranges, unique IDs)
Duplicates
0 duplicate IDs · 35 duplicate rows · 56 duplicate feature vectors (21 with conflicting labels)
Overlap
11 test rows (0.18%) share a feature vector with a training row
Split
The table has no application date: every row covers the same April-September 2005 statement window and the label is default in October 2005. A time-based split is therefore impossible; the split is stratified random (seeded). All features are observed before the label month, so there is no look-ahead inside a row, but the test set comes from the same period as training, so the reported metrics measure in-period generalisation, not performance on a later cohort.

Leakage and split checks

Strongest single features (univariate ROC-AUC): PAY_0 0.690, PAY_2 0.639, PAY_3 0.624, LIMIT_BAL 0.618, PAY_AMT1 0.611.

  • PASS ID and target are not model inputs
  • PASS train / calibration / validation / test are disjoint by ID
  • PASS no single feature has univariate ROC-AUC >= 0.9
  • PASS feature engineering is row-wise (a row gets the same features alone as in a batch), so it cannot carry statistics from other rows or splits
